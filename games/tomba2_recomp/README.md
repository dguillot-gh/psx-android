# Tomba! 2 - The Evil Swine Return Recomp

PSX static recompilation of **Tomba! 2 - The Evil Swine Return** using [PSXRecomp](https://github.com/mstan/psxrecomp).

## Quick start

1. Provide a legal disc image (`.cue` + `.bin`) matching the path in `game.toml`
2. Run `build.ps1` (Windows) or `build.sh` (Linux/macOS)
3. Launch the generated executable
